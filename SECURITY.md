# Security Policy

## Supported Versions

We release patches and security fixes for the current and recent major versions.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

The project team takes the security of `let-it-blossom` seriously.

If you believe you have discovered a vulnerability, please report it responsibly:

- **Preferred (Private Disclosure):** Open a private security advisory via [GitHub Security Advisories](https://github.com/austinhttps/let-it-blossom/security/advisories/new).
- **Email:** Contact Austin directly at [austinjmirando@gmail.com](mailto:austinjmirando@gmail.com) with details including reproduction steps and environment information.

### What to Expect

- **Initial Response:** You will receive an acknowledgment within 48 hours.
- **Triage & Remediation:** We will assess severity, create a fix in a private branch, and coordinate a patch release.
- **Credit:** We will gladly credit you in our release notes and advisory (unless you request to remain anonymous).

Please do not open public GitHub issues for undisclosed security vulnerabilities.
