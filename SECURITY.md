# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| 0.0.0   | :x:                |

## Reporting a Vulnerability

Report a vulnerability through these two sites:
- [GitHub Security Vulnerability](https://github.com/austinhttps/let-it-blossom/security/advisories)
- [NPM Package](https://www.npmjs.com/package/let-it-blossom)
